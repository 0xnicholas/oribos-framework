# 定位重裁:转向追赶 mastra(轻量轴保留)

2026-10-11 裁决:**oribos 转向追赶 mastra,轻量轴保留**。本 ADR 取代 ADR-0016(同日较早「维持有意分叉,不转向」的裁决作废;该文不删不改,dated records 惯例,取代关系以本文为声明)。性质:**owner 行使决定权的硬转,不是条件触发的翻案**——ADR-0016 自写的重开条件(「谁转投、凭什么」的可答赢面假说 / 利基痛点证据消失)均未满足;反方证据(#150:mastra 增长归因 TS 原生 + DX + 营销而非重型功能面,voice 附装率 1.5% / evals 12%;转向须交出唯一有近义痛点证据的差异轴)已完整呈给 owner,owner 仍决定转。转向理由(owner 陈述,如实记):两波地图(完善阶段 / 信号源建设期)全部产出为判定与文档、零功能增量,「不转向」纪律下路线图没有功能面出口。**红线分叉点裁决 = 保轴**:轻量轴两层含义(按需组合 + 无运行时负担,ADR-0001)原样保留,追赶面 = 与两含义兼容的 mastra 功能面子集——挡路的从来不是零依赖硬闸门(能力包可携外部依赖,MCP SDK / OTel 栈已有先例),而是「无运行时负担」:OM 类常驻后台 LLM 管线、voice、重型集成等强制常驻管线/服务的行,保轴下仍不可直行(重判出可嵌入形态者除外)。禁跟单纪律改写:**「mastra 已采用且未弃的功能面 = 需求证据(二手需求)」**,构成该行进入重估的合法触发。目的重定义:从「利基痛点替代」改为「追赶采用」——以 mastra 已验证的需求面为路线图输入,在轻量轴约束内交付兼容能力。

## 逐项表态

- **ADR-0016 处置**:作废,本 ADR 取代;原文与 #149–#157 各票不删不改(dated records)。
- **ADR-0001(轻量定义)**:**保留原样**——保轴的直接后果;轴的两层含义与「数字仅内部参考」口径不变。
- **ADR-0015(CI 轻量红线)**:**保留原样**——零依赖硬闸门 / 字节预算黄灯 / deps-budget / export-surface 机器不动;追赶面新功能行走既有闸门,能力包携依赖沿 ADR-0015 M5 修订(白名单 + deps-budget)口径。
- **ADR-0012(多 agent as-tool)**:**本体保留,演化门触发条款修订**——原触发(as-tool 真实痛点 ≥3 次复述 / ≥1 项目受阻)作废,改受新纪律:mastra 已采用即需求证据。supervisor 方向 mastra 官方迁移文档已确认(「development now focuses on supervisor agents」,gap analysis §2 多 agent 行),需求证据成立 → 「Supervisor 能力包」行进入首批重估;落点纪律不变(能力包优先,全部可建于公开表面;仅当能力包证明需要核心新缝时才以 minor 字段进核心)。
- **禁跟单纪律改写**:原纪律(「mastra 有 / 以后有用 / 不贵」不构成提升理由;重开条件钉需求侧)作废,改写为——**mastra 已采用且仍在维护的功能面 = 需求证据(二手需求),是进入重估的合法触发**。边界(防纪律彻底失效):(1) 触发的是**重估**,不是自动晋升——ROADMAP「满足即单独评估,不自动晋升、不是排期承诺」形状保留;(2) 重估判定 = 轴兼容(保轴红线)+ 承载缝核对,逐行落票;(3) mastra 已裁/弃用的方向(如 `.network()`)不构成证据;(4) 纯营销动作(落地页头条化、pricing 卡位等非实装变化)不构成证据——证据 = 上游实装存在且未弃。
- **追赶面定义**:与轻量轴两含义兼容的 mastra 功能面子集。延后档 13 行多数承载缝 = 能力包(闸门不挡),出域档 7 行解封后逐行重判;首批范围由规划型地图按「与现有承载缝最近」圈定。
- **目的**:追赶采用——以 mastra 已验证的需求面为路线图输入,在轻量轴约束内交付兼容能力,争取 mastra 品类选型者中的轻量诉求段。可观测检验(同时是本裁决自己的重开条件):追赶面交付后采用曲线(下载 / 真实使用信号)无实质起色,或 mastra 侧重大形态变化使兼容面定义失效 → 本裁决可再翻案(届时 dated records 链已四层:#149 → #151 → ADR-0016 → 本件)。

## 翻案程序(执行归规划型地图)

- **110 行有意分叉**(八篇规范「砍单与承载缝」表):逐行重判,三态 = **维持分叉**(轴冲突或语义仍更优;理由照常写明)/ **转追赶项**(立实施票,带验证面)/ **维持分叉但理由改写**(对照 mastra 现状重述)。不必在裁决票逐行判完;程序与首批范围由地图圈定,判定结论落回各篇规范表(单一真相源不变)。
- **延后清单 20 行**:原需求侧重开条件**全部作废**,按新纪律(mastra 采用 = 需求证据)重估;「重开条件」单一真相源地位随本裁决终结,重判结论逐行改记。
- **出域档 7 行**:**自动解封**(其重开条件 = 定位裁决改变,已满足)——解封 = 进入重估,不是晋升;保轴下产品面 / 常驻管线类行预期多数仍维持出域,但须逐行判过才算数。

## Considered Options

- **废/改轴转向**(重写或退役轻量定义,拆除/改写 ADR-0001/0015 机器,全量 parity 含常驻管线与重型集成):被否——品牌与产品实质更换;买到的恰是采用证据最薄的行(voice 1.5% / evals 12% / OM 无分离用量证据,#150),交出的是唯一有近义痛点证据的差异轴(edge 部署受阻 mastra#3309、框架 overhead 公开抱怨);CI 机器拆除是不可逆的额外账单,且废轴后 oribos = 「更晚且同样重的 mastra」,「谁转投、凭什么」彻底无答。
- **维持(ADR-0016 原样)**:被否——owner 行使决定权推翻;两波地图零功能产出,owner 不接受事件驱动静默的延续。
- **转向但不落记录直接开工**:被否——静默转向 = 撤销裁决且扯断引用链;删记录先例已被否(owner 曾提议删两波地图记录,被劝阻并接受),硬转必须走记录正门。

## Consequences

- 信号源建设期即日终结:ROADMAP「下一阶段(信号源建设期)」段改题收口,「0.7 不存在」裁决随硬转作废(功能面入口不再是延后清单重开条件,而是追赶面重估);CONTEXT「信号源建设期」词条注记终态。本期产出(公开叙事两层结构、发现面、skills 包)不撤销——采用与上手面在追赶定位下仍是正资产,逐件重估归后续叙事票。
- 重判执行归规划型 wayfinder 地图(沿 #102 / #149 先例),首批从与现有承载缝最近的行起步(各行「承载缝」列已写明落点);实施沿两段式先例另开地图,`pnpm verify` 全绿是硬门。
- 叙事层最后动:README / topics / `skills/oribos/SKILL.md` / 仓 description 按「不追赶」正典建成,转向后需再次翻转——这是公开记录里第三次定位摆动,翻转文案必须写明理由;翻转归 ADR-0017 后的叙事票,oribos-website / oribos-docs 归各自仓库动线。
- CI 机器零改动:转向不增加闸门成本;新功能行(含能力包携外部依赖)全部走既有闸门与预算口径。
