# 定位根裁决:维持有意分叉,不转向追赶 mastra

2026-10-11 裁决:**oribos 维持有意分叉定位,不转向追赶 mastra**。触发:三路 0.7 候选池在现行纪律(禁跟单 + 需求侧重开条件)下全空,owner 不接受事件驱动静默,提定位重估。事实底座(mastra 采用度调研)显示:mastra 近半年周下载 2.7x 的增长归因 TS 原生 + batteries-included DX + 营销放大,而非重型功能面(voice 附装率 1.5%、evals 12%)——追赶复制的是不驱动增长的表面,且须改写轻量红线(零依赖硬闸门在结构上禁止 OM 类后台管线),交出唯一有近义痛点证据(edge 部署受阻、框架 overhead)的差异轴;「更晚更小的 mastra」答不出谁转投、凭什么。空池根因 = 需求侧信号以用户基数为前提而框架首发仅一周:结构性静默,不是定位失败的证据。裁决:ADR-0001/0012/0015 保留原样;禁跟单纪律保留,增补信号源条款(轴级公开痛点证据是定位/市场面工作的合法输入,不构成延后清单功能行的晋升理由);追认公开叙事两层结构(品类语言 + 能力广度 + 零依赖事实担纲,「轻量」退为内部轴名,oribos-website 已先行执行);静默期姿态 = 信号源建设期(主题为采用与上手面,功能面不动)。

## Considered Options

- **转向追赶 mastra**(接受「mastra 采用即需求证据」,翻案 110 行有意分叉 + 20 行延后清单,改写轻量红线):被否。追赶面 = 证据上用户不用的重型功能;红线改写 = 交出唯一有痛点证据的差异轴;无「谁转投、凭什么」的赢面假说。
- **维持 + 事件驱动静默**(空 0.7,工作只由外部信号触发):被否。无用户期信号源缺席,纯事件驱动没有出口——仪器永远失聪,空池静默无限期延续。
- **维持 + 放宽重开条件阈值**:被否。口径过紧不是病根(首次全量核对零行触发,与上游时钟解耦生效);放宽阈值只会让无源仪器报假警。

## Consequences

- 延后清单出域档 7 行(重开条件 = 定位裁决改变)维持封存;「追赶面定义」不立案。
- ROADMAP 处置归「任务:路线图处置成文」票:新增信号源建设期段、纪律增补条款落判定口径行、开头定位句按两层结构改写。
- 公开面口径:oribos-website(commit 788a563)为公开叙事正典;框架 README 与 oribos-docs 的 ultralight 旧口径失同步,同步归实施 effort。
- 本裁决的重开条件:出现「谁转投、凭什么」的可答赢面假说,或利基痛点证据消失。
